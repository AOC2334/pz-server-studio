# 游戏 IPv6 与域名连接

2026-10-05，本机 Dedicated Server 42.21.0 在独立目录、独立端口的启动探测中拒绝 `-ip ::1`：`expected IP address after "-ip", got "::1"`。现有 kkdy 监听 IPv4 UDP 16261/16262。本方案是 UDP 转发，不修改游戏二进制，不中断当前服务器，不声明游戏原生支持 IPv6。

## 服务器

先正常启动 kkdy，再运行项目根目录的 `启动游戏IPv6入口.cmd`。入口仅监听 IPv6 UDP 16261/16262，转发到本机 IPv4 相同端口。配置在 `config/game-ipv6.json`。关闭该窗口即可停止转发。当前已启动的隐藏入口日志位于 `data/game-ipv6-out.log`，不要同时启动第二份入口。

Windows 防火墙和路由器 IPv6 入站规则均需允许 UDP 16261、16262。公网实测必须使用另一网络的设备，本机回环测试不证明公网可达。

## 玩家

客户端游戏本身也可能不接受纯 IPv6 或仅 AAAA 的域名，因此提供玩家转发工具。玩家需要 Node.js 20 或以上，将 `lib/udp-relay.js`、`scripts/game-ipv6-relay.js`、`config/game-ipv6.json`、`启动玩家IPv6连接.cmd` 按原目录结构放在同一文件夹。

运行 `启动玩家IPv6连接.cmd`，游戏加入地址填 `127.0.0.1`，端口填 `16261`，工具会经 `aoc-applepie.work` 的 IPv6 转发。客户端和服务器仍须使用相同 Steam 模式、游戏版本、模组。服务器本机已经占用这两个 IPv4 端口，不能同时运行玩家工具；本机直接用 127.0.0.1 入服。

## 域名

本次 DNS 查询：AAAA 为 `2408:8360:8231:4f80:6a67:c15:d3ef:8539`，与本机以太网公网 IPv6 一致；无 A 记录。玩家工具按域名解析 IPv6，不写死地址。公网 IPv6 变化后需要更新域名 AAAA。游戏 UDP 不使用 HTTP Host 白名单。常规网页代理不能代理这两个游戏 UDP 端口。

验证已覆盖两名独立客户端 UDP 往返与响应隔离；真实游戏经转发入服、Steam 直连/中继选择和外网连通仍需玩家实测。
